# Full-day traffic-density profile

`fig_diurnal.pdf` / `fig_diurnal.png` show the hourly mean vehicle population (vehicles per non-empty frame) of the continuous 24-hour trajectory, the four targeted evaluation periods and the densities of the cold-start windows evaluated in the matched warm/cold experiment (one point per distinct start time in `data/paired/eval_sequence_<period>.csv`). The figure is generated by `analysis/make_tables.py`.

The figure is supplied as supplementary evaluation-design evidence. It was removed from the main paper for space because:

- the Section 5 results visual identifies the targeted operating conditions;
- the Section 6 warm/cold table reports the initialisation-induced density difference; and
- the protocol does not require a separate full-day density figure to be understood.

The plot should not be interpreted as estimating a continuous causal response to density. The selected periods are observational slices in which density co-varies with workload, speed, spatial configuration and peer availability.
